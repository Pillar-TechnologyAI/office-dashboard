Privacy Policy

Last updated: November 11, 2026

Office Dashboard is a personal, self-hosted app that displays its owner's calendar on a TV inside their home.

What data the app accesses

With the user's permission, the app uses the Google Calendar read-only scope (calendar.readonly) to read the list of calendars and the events on them: titles, times, all-day status and locations. It does not access email, contacts, files or any other Google data, and it cannot create, change or delete events.

How the data is used

Event data is used only to draw the dashboard screen. Events are kept in memory on the owner's own device and refreshed about once a minute. They are not written to any database.

Where the data is stored

The only thing saved is the Google sign-in token, stored on the owner's own network storage device inside their home. No data is sent to the app developer or to any third-party server, and nothing is stored in the cloud apart from Google itself.

Sharing

Google user data is never sold, shared, transferred or used for advertising. It is never used to train AI or machine-learning models. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

You can revoke the app's access at any time at myaccount.google.com/connections. Revoking access stops all further reads. Deleting the token file on the device removes the only stored data.

Contact

Questions about this policy can be raised through this site's GitHub repository.
